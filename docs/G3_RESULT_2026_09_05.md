# G3 model execution result — 2026-09-05

The frozen G3 protocol passed in three independent processes on the Apple M4.
The [ten-file result bundle](../results/g3/apple-m4-primary/README.md) retains
the complete session objects, raw timings, token IDs, correctness, coverage,
environment and provenance. Its producer revision is
`ad15f5d293722a615b1440b320e4197126500f36`.

Run the independent verification with:

```sh
make verify-g3-result BUNDLE=results/g3/apple-m4-primary
```

## What the evidence establishes

- All 22 query-projection adapters were installed and later restored, with zero
  live adapters and in-flight calls at cleanup.
- All 22 layers exercised same-Q8 prefill fallback and native cached decode.
- Each session passed 22 preinstallation probes, 1,848 native-output checks,
  96 model-logit comparisons and exact token-ID agreement for 12 path pairs.
- Each session retained two warmup and ten measured generations per path;
  across the three processes there are 60 measured generations and 12 warmups.
- Both paths passed the frozen drift interval of 0.9–1.1 in every session.

## Measured boundary

| Quantity | Observed value |
| --- | --- |
| Same-Q8 reference, pooled median total generation | 1.732111104 seconds |
| Hybrid native, pooled median total generation | 0.751341583 seconds |
| Cold startup, three processes | 23.055, 19.824 and 18.530 seconds |
| Peak process RSS, three processes | 4.878, 4.898 and 4.919 GiB |
| Fresh offline asset preparation | 54.102 seconds |

The two pooled medians describe the full guarded, instrumented implementations
under the frozen eight-token protocol. The reference path clones and hashes
the FP32 fallback weights on each call; hooks clone projection inputs and
outputs in both paths. Isolated native-work timing is unavailable. These
numbers are not a stock-PyTorch comparison, a kernel-only speedup or a
confidence interval. Preparation and cold startup are reported separately
from warmed generation. The retained analysis supplies the exact fractions
and raw observations underlying the rounded values above.

## Text quality remains a limitation

The frozen prompt is `Write one short sentence about a compiler.` Every path
produced the same eight token IDs:

```text
2, 29871, 13, 29966, 29989, 465, 22137, 29989
```

The decoded text is `</s> \n<|assistant|` (where `\n` represents a newline).
It is control-token text, not a useful sentence. The fixed protocol explicitly
treats generated text as demonstration output rather than correctness proof,
so this does not invalidate its numeric and execution checks. It does limit
the quality of a user-facing demonstration.

A separately specified chat-template/prompt experiment is the next presentation
task. The accepted prompt, token IDs and result are preserved; no prompt was
changed after observing this output.
